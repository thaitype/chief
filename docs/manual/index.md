# Chief Documentation

Chief is a structured workflow for AI coding agents. These docs follow the [Diátaxis](https://diataxis.fr/) framework — each section has a different purpose.

| Section | Purpose | Start here when… |
|---|---|---|
| [Tutorials](tutorials/) | Learning by doing | You're new to Chief |
| [How-to guides](how-to/) | Solving a specific problem | You know Chief and need to do something concrete |
| [Reference](reference/) | Looking something up | You need accurate technical details |
| [Explanation](explanation/) | Understanding why | You want to understand the design decisions |
